Notatnik w C++ 📓

Graficzna aplikacja typu notatnik stworzona w języku C++ jako element nauki programowania obiektowego. Projekt inspirowany materiałami z kursu Mirosława Zelenta (Pasja Informatyki), szczególnie dotyczącymi tworzenia prostych aplikacji okienkowych z użyciem Windows API.

🎥 Demo

Zobacz, jak działa aplikacja:  
https://youtu.be/2te3l1iMSm0

🎓 Kontekst

Projekt został stworzony w ramach kursu programowania obiektowego w języku C++ autorstwa Mirosława Zelenta.
Celem było praktyczne przećwiczenie tworzenia aplikacji okienkowej (WinAPI) z zastosowaniem klas, dziedziczenia oraz obsługi zdarzeń.

🛠 Funkcje aplikacji

- Interfejs graficzny (Windows API)
- Otwieranie i zapisywanie plików tekstowych
- Edytowanie tekstu
- Prosty układ menu (Plik, Edycja, itp.)
- Obsługa skrótów klawiszowych

🧰 Wymagania

- System Windows
- Kompilator C++ obsługujący WinAPI (np. MinGW, MSVC)
- Środowisko programistyczne (np. Code::Blocks, Visual Studio)

🚀 Kompilacja i uruchamianie

1. Sklonuj repozytorium:
   git clone https://github.com/psujex24/notepad.git
   cd notepad

2. Otwórz plik .cpp w środowisku programistycznym i skompiluj jako aplikację Windows (Win32 API).
   Upewnij się, że Twój projekt ma ustawiony typ jako "GUI Application", nie "Console".

⚠️ Uwaga

Ten projekt miał charakter edukacyjny i nie jest rozwijany jako pełnoprawny edytor tekstu. Może zawierać uproszczenia lub ograniczenia wynikające z jego dydaktycznego celu.

✅ Status projektu

Projekt został zakończony i nie jest obecnie rozwijany. Stanowi zamknięty etap nauki programowania w C++.
